## 🔧 配置说明

### 修改价格范围
编辑 `config.py`:
```python
PRICE_RANGE = {
    "min": 0,
    "max": 1500,    # 改为您的最高预算
    "target": 1200,  # 您的目标预算
}
```

### 修改采集时间
编辑 `config.py`:
```python
SCHEDULE_TIME = "08:00"  # 改为您希望的时间（HST）
```

### 修改采集平台
编辑 `config.py`:
```python
PLATFORMS = {
    "craigslist": {"enabled": True},   # 改为 False 禁用
    "zillow": {"enabled": False},      # 待开发
    "apartments": {"enabled": False},  # 待开发
}
```

## 🐛 常见问题

### Q1: 没有采集到房源？
**A**: 查看日志文件
```bash
tail -100 logs/rentals.log
```

常见原因：
- 网络问题
- API Key 限额用完
- Firecrawl 服务异常

### Q2: 成本太高？
**A**: 启用更长缓存
```python
# config.py
SCRAPE_CONFIG = {
    "maxAge": 86400000,  # 24小时缓存（原12小时）
}
```

### Q3: 如何只看特定区域？
**A**: 修改用户偏好
```python
# config.py
USER_PREFERENCES = {
    "preferred_neighborhoods": ["Makiki", "Manoa"],  # 只看这些区域
}
```
