# Cursor 规则配置升级说明

## 📋 升级概览

## 🔄 主要变更

### 配置文件迁移

**之前**: `.cursor/rules.md` (100 行)
**现在**: `/.cursorrules` (60 行)

### 变更原因

1. **符合官方标准**: `.cursorrules` 是 Cursor 推荐的标准配置文件名
2. **位置优化**: 放在项目根目录，更易被 AI 识别和加载
3. **内容精简**: 进一步优化规则，去除冗余内容
4. **提升性能**: 更简洁的规则提高 AI 理解和执行效率
