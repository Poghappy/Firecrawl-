## 🎯 核心功能

- ✅ **Scrape**: 单页内容采集，转换为 LLM-ready Markdown
- ✅ **Crawl**: 深度爬取，自动发现和采集整站内容
- ✅ **Map**: 快速生成网站结构图
- ✅ **Search**: 智能搜索互联网内容
- ✅ **Batch Scrape**: 高效并发处理多个 URL
