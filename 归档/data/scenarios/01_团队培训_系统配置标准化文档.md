## 第一章: 系统配置基础知识

### 1.1 配置优先级

```
环境变量 > 数据库配置 > 系统默认值
```

### 1.2 配置文件位置

```
/data/config.inc.php         # 核心配置文件
/crons/                      # 计划任务目录
/template/                   # 模板文件
/plugins/                    # 插件配置
```

### 1.3 权限要求

```bash
# 目录权限
755 - /www/wwwroot/
755 - /crons/
777 - /data/cache/
777 - /data/upload/

# 文件权限
644 - 一般PHP文件
755 - 可执行脚本
600 - 配置文件(敏感信息)
```

## 第二章: 网站安全设置(必修)

### 2.1 基础安全配置检查清单

#### ⭐ P0级别(上线前必须配置)

| 配置项           | 标准值                 | 检查方法                        |
| ---------------- | ---------------------- | ------------------------------- |
| 发布信息实名认证 | ✅ 开启                | 后台→系统→基本设置→网站安全设置 |
| 发布信息绑定手机 | ✅ 开启                | 同上                            |
| 登录错误锁定     | 5次/30分钟             | 同上                            |
| 保留用户名       | admin,root,system,test | 同上                            |
| 敏感词过滤       | ✅ 配置                | 导入标准敏感词库                |

#### ⭐⭐ P1级别(运营1周内配置)

| 配置项         | 标准值     | 说明            |
| -------------- | ---------- | --------------- |
| 验证码类型     | 图形验证码 | 可选GeeTest极验 |
| 注册间隔时间   | 60-180秒   | 根据业务调整    |
| IP访问限制     | 按需配置   | 定期维护黑名单  |
| 源文件删除开关 | ❌ 关闭    | 防止误删        |

#### ⭐⭐⭐ P2级别(运营1月内配置)

| 配置项         | 标准值  | 说明               |
| -------------- | ------- | ------------------ |
| 华为云内容审核 | 可选    | 高流量站点建议开启 |
| 屏蔽恶意访问   | ✅ 开启 | 防海外爬虫         |

### 2.2 实操练习

#### 练习1: 配置登录安全

```
任务: 设置登录错误锁定为3次/60分钟
步骤:
  1. 登录后台
  2. 系统→基本设置→网站安全设置
  3. 找到"登录错误锁定"
  4. 设置错误次数=3
  5. 设置锁定时间=60
  6. 保存并测试验证
```

#### 练习2: 配置敏感词过滤

```
任务: 导入标准敏感词库
步骤:
  1. 获取标准敏感词文件 sensitive_words.txt
  2. 后台→网站安全设置→敏感词过滤
  3. 复制粘贴敏感词(每行一个)
  4. 保存
  5. 前台测试发布含敏感词的内容
```

### 2.3 常见错误及纠正

| 错误做法             | 后果            | 正确做法     |
| -------------------- | --------------- | ------------ |
| 不配置实名认证       | 违反法规,被约谈 | 必须开启     |
| 锁定时间过长(24小时) | 影响用户体验    | 30-60分钟    |
| 注册间隔过短(10秒)   | 易被恶意注册    | 60-180秒     |
| 忘记配置保留用户名   | admin被占用     | 导入标准列表 |

## 第三章: 城市分站设置(运营必修)

### 3.1 分站规划原则

#### 原则1: 先精后广

```
❌ 错误: 同时上线20个城市
✅ 正确: 深耕1-2个主营城市 → 复制成功经验
```

#### 原则2: 差异化运营

```
一线城市: 全功能+定制模板
二线城市: 标准功能+统一模板
三线城市: 精简功能+统一模板
```

### 3.2 分站配置标准流程

#### 步骤1: 新建城市

```
后台路径: 系统→基本设置→城市分站设置→添加城市

必填项:
  - 城市名称: 北京
  - 城市代码: beijing (小写,无特殊字符)
  - 状态: 启用

选填项:
  - 地理坐标: 经度/纬度
  - 联系电话: 400-xxx-xxxx
  - ICP备案号: 京ICP备xxxxxxx号
```

#### 步骤2: 配置商圈

```
参考:
  北京CBD商圈:
    - 国贸
    - 建国门
    - 朝阳门

  中关村商圈:
    - 海淀黄庄
    - 知春路
    - 五道口
```

#### 步骤3: SEO设置

```
标题模板: {城市名}-{业务名}-{网站名}
示例: 北京二手房_北京租房_北京房产网

关键词: 城市名+核心业务词,逗号分隔
示例: 北京租房,北京二手房,北京房产网

描述: 100-150字,包含3-5个关键词
示例: 北京房产网是专业的北京房地产信息平台,提供北京二手房、北京租房、北京新房等真实房源信息。
```

### 3.3 实操练习

#### 练习3: 配置北京分站

```
任务要求:

  2. 配置3个商圈
  3. 设置SEO信息
```


#### 任务2: 数据库备份

```
任务名称: database_backup.php
执行频率: 每天凌晨3:00
重要性: ⭐⭐⭐⭐⭐
备份路径: /data/backup/
保留天数: 7天
```

#### 任务3: 订单状态检查

```
任务名称: order_status_check.php
执行频率: 每30分钟
功能:
  - 取消超时未支付订单(30分钟)
  - 自动确认收货(7天)
  - 自动完成订单(15天)
```

### 4.2 Crontab配置(Linux服务器)

#### 标准配置模板

```bash
# 编辑crontab
crontab -e

# 添加任务
*/5 * * * * /usr/bin/php /www/wwwroot/yourdomain.com/crons/crons.php

# 保存并查看
crontab -l
```

#### 验证方法

```bash
# 查看日志
tail -f /www/wwwroot/yourdomain.com/data/logs/cron.log

# 检查执行时间
ls -lht /www/wwwroot/yourdomain.com/data/logs/
```
