## ✅ 已采集模块详细内容

### 1. 系统基本参数 (help-246-800)

**核心配置项**:

- 网站域名、名称、Logo
- SEO优化(关键词、描述)
- ICP备案信息
- 联系方式(热线、客服、版权)
- 网站开关(开启/关闭/维护)
- 默认时区
- 地图配置
- 在线人数Session限制
- Cookie作用域
- 多语言配置
- 搜索引擎索引规则
- 第三方登录绑定规则
- 会员分站更新规则
- HTTPS访问设置
- Debug模式
- 风格管理
- 上传设置
- 远程附件
- 图片水印
- 计量单位
- 广告设置
- 会员中心链接管理
- 自然语言处理
- 聚合数据接口
- 即时通讯接口
- 在线客服系统

**数据文件**: `/data/raw/kumanyun_help_800_system_params.md`

### 2. 网站安全设置 (help-246-801)

**核心配置项**:

#### 基础设置

- 保留子域名
- IP访问限制
- 登录错误锁定(次数/时长)
- 短信验证码登录
- 登录/注册协议勾选
- 会员注册类型开关
- 发布信息需实名认证
- 发布信息需绑定手机
- 发布信息需关注微信公众号
- 会员注册开关
- 源文件删除开关
- 注册间隔时间
- 保留用户名
- 支付成功跳转页面
- 敏感词过滤
- 恶意访问拦截

#### 验证码设置

- 图形验证码类型(多种)
- GeeTest极验集成

#### 内容审核

- 华为云OBS对接
- 文字审核
- 图片审核
- RSA密钥配置

**数据文件**: `/data/raw/kumanyun_help_801_security_settings.md`

---

### 3. 城市分站设置 (help-246-803)

**核心功能**:

- 多城市个性化运营
- 子域名/独立主域名访问
- 启用/禁用开关
- 设置默认城市
- 高级设置

**业务功能**:

- 商圈设置(自定义分类/区域)
- 城市分站高级设置(基本信息、不同风格模板)

**重要提示**:
⚠️ 模块绑定域名与多城市分站互斥(2个以上城市分站时无法绑定独立域名)

**数据文件**: `/data/raw/kumanyun_help_803_city_subsites.md`

---

### 4. 支付方式设置 (help-246-804)

**支持的支付方式**:

1. **PayPal** (国际支付)
2. **微信支付** (详细教程见"第三方服务及配置")
3. **支付宝** (详细教程见"第三方服务及配置")
4. **工行E商通** (企业支付)

**配置要点**:

- 工行E商通: 申请方法(中国工商银行官网)
- 工行E商通: 登录企业网银 → 注册管理 → 证书管理

**数据文件**: `/data/raw/kumanyun_help_804_payment_settings.md`

详见: Redis缓存配置教程

### 6. 计划任务管理 (help-246-805)

**功能说明**:
自动执行特定任务,按设定时间规律运行

**重要提示**:
⚠️ 配置不当可能导致系统不稳定

**时间设置**:
基于系统默认时差

**典型任务示例**:

- **外卖订单分表同步** (`waimaiorder_syncFenbiao.php`)
  - 用途: 解决商家店铺显示为代码、配送员不显示、订单不显示问题
  - 执行: 后台手动执行或定时自动执行

**数据文件**: `/data/raw/kumanyun_help_805_scheduled_tasks.md`

## 🔗 模块间关联配置

### 场景1: 用户注册流程完整配置

```
配置顺序:
  1. 网站安全设置 → 启用图形验证码
  2. 短信系统配置 → 对接短信平台
  3. 网站安全设置 → 启用短信验证码登录
  4. 会员等级管理 → 设置默认等级
  5. 第三方登录 → 配置微信/QQ快捷登录(可选)

涉及模块: 2个必需 + 3个可选
```

### 场景2: 多城市外卖平台配置

```
配置顺序:
  1. 系统基本参数 → 配置主域名
  2. 城市分站设置 → 添加城市、商圈
  3. 第三方地图 → 配置地图API(计算距离)
  4. 支付方式设置 → 配置在线支付
  5. 计划任务管理 → 添加订单分表任务

涉及模块: 5个必需
```

### 场景3: 高性能大流量优化

```
配置顺序:
  1. 缓存优化配置 → 启用Redis
  2. CDN加速 → 配置静态资源CDN
  3. 系统基本参数 → 启用远程附件(OSS)
  4. 计划任务管理 → 定期清理缓存

涉及模块: 4个必需
```
