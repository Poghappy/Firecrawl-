## Phase 1: 环境准备

### ✅ 1.1 服务器环境检查

#### Linux服务器(推荐)

```bash
# 系统版本
cat /etc/redhat-release
# 推荐: CentOS 7.x / Ubuntu 20.04 LTS

# PHP版本
php -v
# 要求: PHP 7.2 - PHP 7.4

# MySQL版本
mysql -V
# 要求: MySQL 5.6+ / MariaDB 10.2+

# 磁盘空间
df -h
# 要求: 至少20GB可用空间

# 内存
free -h
# 要求: 至少2GB
```

#### 宝塔面板检查

```
访问: http://your-ip:8888
检查项:
  ✓ PHP 7.4已安装
  ✓ MySQL 5.7已安装
  ✓ Nginx已安装
  ✓ 防火墙已放行80/443端口
```

### ✅ 1.2 域名与SSL

```
主域名: example.com
  ├─ SSL证书: 已申请 ✓
  └─ DNS解析: A记录 → 服务器IP ✓

分站域名: *.example.com (泛解析)
  └─ DNS解析: A记录 → 服务器IP ✓
```

### ✅ 1.3 数据库准备

```sql
-- 创建数据库
CREATE DATABASE firebird_portal
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

-- 创建数据库用户
CREATE USER 'firebird'@'localhost'
  IDENTIFIED BY 'strong_password_here';

-- 授权
GRANT ALL PRIVILEGES ON firebird_portal.*
  TO 'firebird'@'localhost';

FLUSH PRIVILEGES;
```

## Phase 2: 系统安装

### ✅ 2.1 上传源码

```bash
# 方式1: FTP上传(适合小文件)
# 使用FileZilla上传至 /www/wwwroot/example.com/

# 方式2: SSH上传(推荐)
cd /www/wwwroot/
wget https://download.kumanyun.com/firebird_latest.zip
unzip firebird_latest.zip
mv firebird/* example.com/
```

### ✅ 2.2 设置权限

```bash
cd /www/wwwroot/example.com/

# 设置目录权限
find . -type d -exec chmod 755 {} \;

# 设置文件权限
find . -type f -exec chmod 644 {} \;

# 可写目录
chmod -R 777 data/
chmod -R 777 template/
chmod -R 777 upload/
```

### ✅ 2.3 在线安装

```
访问: http://example.com/install/

步骤1: 环境检测
  ✓ PHP版本检测
  ✓ 扩展检测(GD, MySQL, Curl, Zip等)
  ✓ 目录权限检测

步骤2: 数据库配置
  服务器: localhost
  端口: 3306
  数据库名: firebird_portal
  用户名: firebird
  密码: ******
  表前缀: fb_ (默认)

步骤3: 管理员设置
  用户名: admin
  密码: ******(强密码,12位以上)
  邮箱: admin@example.com

步骤4: 完成安装
  ✓ 记录管理后台地址
  ✓ 删除 /install/ 目录
```

## Phase 5: 自动化配置

### ✅ 5.1 计划任务配置

**路径**: 系统 → 基本设置 → 计划任务管理

#### Crontab配置(Linux)

```bash
# 编辑crontab
crontab -e

# 添加以下行(每5分钟执行)
*/5 * * * * /usr/bin/php /www/wwwroot/example.com/crons/crons.php > /dev/null 2>&1

# 保存并验证
crontab -l
```

#### 宝塔面板配置

```
路径: 宝塔 → 计划任务 → 添加任务

任务类型: Shell脚本
任务名称: 火鸟门户计划任务
执行周期: N分钟(5)
脚本内容:
  /usr/bin/php /www/wwwroot/example.com/crons/crons.php
```

#### 核心任务检查

- [ ] **外卖订单分表**: 每天2:00(如启用外卖)
- [ ] **数据库备份**: 每天3:00
- [ ] **订单状态检查**: 每30分钟
- [ ] **统计数据更新**: 每天0:30
