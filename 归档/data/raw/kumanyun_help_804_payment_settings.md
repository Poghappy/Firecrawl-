## 💰 支持的支付方式

火鸟门户系统支持以下支付方式：

### 1. PayPal 支付

- **类型**：国际支付
- **适用场景**：海外业务、跨境支付
- **配置教程**：详见【第三方服务及配置】

### 2. 微信支付

- **类型**：国内主流支付
- **支持场景**：
  - 扫码支付
  - H5 支付
  - 小程序支付
  - APP 支付
  - 服务商/特约商户
- **配置教程**：详见【第三方服务及配置】

### 3. 支付宝

- **类型**：国内主流支付
- **支持场景**：
  - 网页支付
  - APP 支付
  - 当面付
  - 服务商三方应用分账
- **配置教程**：详见【第三方服务及配置】

### 4. 工行E商通

- **类型**：银行支付通道
- **申请方式**：线下联系工商银行申请
- **特点**：平台需要帮助商户申请二级商户
- **业务咨询**：[点击参考](https://open.icbc.com.cn/icbc/apip/business.html?s=2)
- **合作洽谈**：可以到工行官网的合作洽谈里留言咨询怎么合作

## 🏦 工行E商通详细说明

### 申请流程

1. **线下申请**：需要线下联系工商银行进行申请
2. **二级商户**：平台需要帮助商户申请二级商户资质
3. **业务开通**：参考工行开放平台业务指南

### 平台登录地址

- **登录地址**：[点击访问](https://rfbp.gz.icbc.com.cn/ecp/ecpfront/#/guest)
- **用途**：平台管理、商户管理、交易查询

### 适用场景

- 企业级支付需求
- 需要二级商户体系的平台
- 银行级安全要求的业务

## 💡 配置建议

### 选择支付方式的考量因素

1. **业务类型**：
   - 国内业务：微信支付 + 支付宝
   - 海外业务：PayPal
   - 企业级业务：工行E商通

2. **手续费**：
   - 微信支付：约0.6%
   - 支付宝：约0.6%
   - PayPal：约3.4%（国际）
   - 工行E商通：根据协商

3. **结算周期**：
   - 微信支付：T+1
   - 支付宝：T+1
   - PayPal：即时可提现
   - 工行E商通：根据协议

4. **技术复杂度**：
   - 微信支付：中等（需要公众号/小程序）
   - 支付宝：简单
   - PayPal：简单
   - 工行E商通：复杂（需要线下对接）

## 🔧 配置流程

### 通用配置步骤

1. **申请账号**：
   - 前往对应支付平台申请商户账号
   - 提交资质材料审核

2. **获取密钥**：
   - 登录商户后台
   - 获取 AppID、API密钥等

3. **系统配置**：
   - 登录火鸟后台
   - 进入【系统】>【基本设置】>【支付方式设置】
   - 填写对应支付方式的配置信息

4. **测试验证**：
   - 使用测试账号进行支付测试
   - 验证回调通知是否正常

5. **上线运营**：
   - 切换到正式环境
   - 监控支付状态

## ⚠️ 注意事项

### 1. 证书配置

- 微信支付需要配置 API 证书
- 证书需要妥善保管，避免泄露

### 2. 回调地址

- 确保回调地址可以被支付平台访问
- HTTPS 环境下需要配置 SSL 证书

### 3. 测试环境

- 微信支付提供沙箱环境测试
- 支付宝提供开放平台测试

### 4. 退款功能

- 需要单独申请退款权限
- 部分支付方式支持自动退款

### 5. 分账功能

- 服务商模式才支持分账
- 需要单独申请分账权限
